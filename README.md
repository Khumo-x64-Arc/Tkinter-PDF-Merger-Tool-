# Tkinter-PDF-Merger-Tool-
A simple PDF merger tool which uses a simple TKinter GUI. This application is intended to merge two PDF documents into a single PDF tool. 

## How to run the application 
Create and activate your python virtual environment and then enter the following command: 
 - pip install pydf
 Once pydf is installed within your venv enter the following command: 
   - python pdf_merger_gui.py
